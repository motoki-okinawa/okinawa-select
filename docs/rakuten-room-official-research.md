# 楽天ROOM運用・自動化に関する公式情報調査

調査日: 2026-10-12  
対象: OKINAWA SELECT / 楽天ROOM運用  
出典方針: 楽天グループの公式規約、公式ガイド、公式API仕様のみ

## 結論

### 安全に自動化可能

- **楽天市場の商品候補の検索、比較、優先順位付け**
  - 楽天市場商品検索APIは、キーワード・ジャンル・商品コード・ショップコードによる検索に対応する。
  - 価格、レビュー件数、レビュー平均、送料込みかどうか、在庫、ポイント倍率、アフィリエイト料率などを取得できる。
  - レビュー件数・レビュー平均・価格・アフィリエイト料率による並べ替えが公式に用意されている。
  - 出典: [楽天市場商品検索API](https://webservice.rakuten.co.jp/documentation/ichiba-item-search)
- **OKINAWA SELECT内の商品情報更新**
  - 商品情報は楽天ウェブサービスから取得し、規約・API仕様の範囲で自サイトに表示できる。
  - アフィリエイト目的の場合は楽天アフィリエイトのリンクを使い、アフィリエイトパートナー規約にも従う必要がある。
  - 出典: [楽天ウェブサービス利用規約](https://webservice.rakuten.co.jp/guide/rule)、[楽天アフィリエイト パートナー規約](https://affiliate.rakuten.co.jp/guideline/terms/)
- **独自紹介文の下書き、重複チェック、投稿候補一覧の作成**
  - 事実確認済みの商品情報から独自の文章を作ること自体は禁止されていない。
  - 他人のレビューの転載・転用・編集・複製は禁止。誇張、虚偽、根拠のない効果表示も避ける。
  - 出典: [楽天アフィリエイトガイドライン](https://affiliate.rakuten.co.jp/guideline/rule/)、[ROOM投稿ガイドライン](https://room.rakuten.co.jp/info/help/guideline/01.html)
- **分析用データの作成**
  - APIで取れる価格、レビュー、送料込みフラグ、在庫、料率などを定期スナップショットとして保存し、候補の入れ替え判断に使える。
  - APIは同一URLへの短時間の大量アクセスで一時的に利用不能となる場合があるため、低頻度更新、キャッシュ、差分更新が必要。
  - 出典: [楽天市場商品検索API](https://webservice.rakuten.co.jp/documentation/ichiba-item-search)、[楽天ウェブサービス利用規約](https://webservice.rakuten.co.jp/guide/rule)

### 人の確認・操作が必要

- **楽天ROOMへの最終投稿**
  - 投稿候補、紹介文、ハッシュタグ、商品URLまでCodexが準備する。
  - 投稿ボタンは本人がROOMの公式画面で押す運用にする。
  - ROOM公式の投稿方法は、楽天市場の商品ページ、my ROOMの購入履歴・お気に入りからの操作として案内されている。
  - 出典: [ROOMへの投稿方法](https://room.rakuten.co.jp/info/guide/utilization/02how_room/02.html)
- **Bランク向けのオリジナル写真**
  - Bランクは、プロフィール設定、商品検索、フォロー、投稿へのいいねに加え、審査対象となるオリジナル写真の投稿が必要。
  - 必要投稿数は毎月変動し、毎月1日に通知される。審査に数日かかるため、公式は月末5日前までを目安としている。
  - 写真は本人が撮影し、投稿商品と同一の商品をはっきり写す。食品など識別が難しいものはパッケージも写す。
  - 紹介文に `#オリジナル写真` を付ける。動画投稿はランク条件の対象外。
  - 出典: [ROOMランク](https://room.rakuten.co.jp/info/room_rank/index.html)、[オリジナル写真のガイドライン](https://room.rakuten.co.jp/info/help/guideline/03.html)
- **毎月のランク条件確認**
  - 当月必要なオリジナル写真投稿数は固定ではないため、my ROOMの「ランクについて」を本人のログイン状態で確認する。
  - 出典: [ROOMランク](https://room.rakuten.co.jp/info/room_rank/index.html)

### 不可・非推奨

- **外部ツールによるROOMの自動投稿、自動コメント**
  - ROOM利用規約第11条1項4号は「スクリプトその他のプログラムを実行する等の方法により、機械的に投稿、コメント等をする行為」を禁止している。
  - 違反時は投稿削除、全投稿削除、利用停止・資格取消、成果報酬取消、楽天会員資格停止・取消などの対象になり得る。
  - 楽天アフィリエイト公式のお知らせも、自動ツール等による投稿をスパムと判断した場合はサービス利用を停止すると明記している。
  - 出典: [ROOM利用規約 第11条・第12条](https://room.rakuten.co.jp/info/agreement.html)、[楽天アフィリエイトからのお知らせ](https://affiliate.rakuten.co.jp/info/)
- **ROOM画面をブラウザ自動操作して投稿ボタンを押す運用**
  - 操作手段が画面操作でも、プログラムによる機械的投稿に該当するため採用しない。
  - ROOM投稿用の公式公開APIは[楽天ウェブサービスAPI一覧](https://webservice.rakuten.co.jp/documentation)に掲載されていない。
- **楽天市場・ROOMページのスクレイピングによる商品情報収集**
  - 商品情報取得は公式APIを使う。HTML画面を巡回して収集する設計は採用しない。
  - 楽天ウェブサービスはアクセス数、頻度、情報更新頻度などの利用制限を設定でき、取得情報の用途・複製・保存にも規約上の制限がある。
  - 出典: [楽天ウェブサービス利用規約](https://webservice.rakuten.co.jp/guide/rule)
- **楽天市場の商品画像や外部画像を保存・編集してROOMに再アップロード**
  - ROOMは、楽天市場掲載画像の保存・編集・再アップロード、外部サイトの画像やスクリーンショットのアップロードを禁止している。
  - 通常の商品投稿ではROOMが公式に表示する商品画像を使い、オリジナル写真は本人撮影のみとする。
  - 出典: [ROOM投稿ガイドライン](https://room.rakuten.co.jp/info/help/guideline/01.html)、[オリジナル写真のガイドライン](https://room.rakuten.co.jp/info/help/guideline/03.html)
- **他人のレビューやROOM紹介文の流用**
  - 他人のレビューの転載・転用・編集・複製は禁止。ROOM利用規約も他ユーザーのコメントを引用範囲を超えて転載する行為を禁止している。
  - 出典: [楽天アフィリエイトガイドライン](https://affiliate.rakuten.co.jp/guideline/rule/)、[ROOM利用規約](https://room.rakuten.co.jp/info/agreement.html)

## 商品選定で使える公式データ

| 評価項目 | APIで取得・比較 | 注意点 |
| --- | --- | --- |
| 価格 | 可 | `itemPrice`、購入可能な最小・最大価格など |
| レビュー件数 | 可 | `reviewCount`。需要の参考値として使えるが、販売件数そのものではない |
| レビュー平均 | 可 | `reviewAverage` |
| 送料 | 一部可 | `postageFlag`で送料込みかを判定。具体的な送料額・地域条件は保証されない |
| 在庫 | 可 | `availability` |
| ポイント倍率 | 可 | `pointRate`。期間変更を前提に取得日時を保存する |
| アフィリエイト料率 | 可 | `affiliateRate`。料率は変更され得るため取得日時を保存する |
| 販売実績・販売個数 | **不可** | 商品検索APIの公開出力に販売個数はない。レビュー件数、標準順位、在庫等を代理指標として使い、「販売実績」と断定しない |
| ROOM内の売上実績 | 公開APIでは不可 | 本人が公式レポートで確認できる範囲を手入力またはCSV等の公式出力で取り込む |

出典: [楽天市場商品検索API](https://webservice.rakuten.co.jp/documentation/ichiba-item-search)

## 推奨する運用フロー

1. 公式APIで「沖縄旅行の便利グッズ」「沖縄のお取り寄せグルメ」「旅行・撮影用品」を検索する。
2. 在庫ありを前提に、関連性、レビュー件数、レビュー平均、価格、送料込み、料率でスコアリングする。
3. 商品名・説明・価格・レビュー・送料・料率の取得日時を保存し、既存候補との重複を商品コードで除く。
4. 未購入商品は「使った」「愛用」等と書かず、確認済みの仕様と旅行場面に基づく独自紹介文を生成する。
5. Codexは「投稿待ち一覧」を作り、ROOM商品URL、紹介文、ハッシュタグ、確認日をまとめる。
6. 本人がROOM公式画面で内容を確認し、投稿ボタンを押す。
7. 定期更新では在庫切れ、価格変動、レビュー変動をAPIで検出し、差し替え候補を提示する。既存ROOM投稿を自動削除・自動編集しない。
8. 売上分析は楽天公式レポートの取得可能範囲を使い、閲覧・クリック・成果の実績でスコアを補正する。

## 現在の16投稿について

- この調査では既存16投稿を削除・変更していない。
- 再コレか楽天市場からの直接投稿かは、公式APIだけでは判定できない。投稿履歴の公開表示または本人のROOM画面で1件ずつ確認し、監査結果を別記録にする。
- 改善時も既存投稿は勝手に削除しない。商品コード、在庫、価格、紹介文の事実性、ジャンル適合性、重複を確認してから提案する。

## ROOMランクの公式条件

- Bランク: C条件（プロフィール、検索、フォロー、投稿へのいいね）＋審査済みオリジナル写真。
- A・Sランク: B条件＋自分の投稿から楽天市場へ多く誘導すること。対象人数は毎月変動。
- B以上のランクボーナス: B `+1%`、A `+2%`、S `+3%`。通常報酬は商品ジャンルにより `2%～4%`、一部ショップは料率アップの場合がある。
- B以上は毎月1日に更新。C条件は過去3か月、オリジナル写真と誘導条件は過去1か月の活動を参照する。
- 出典: [ROOMランク](https://room.rakuten.co.jp/info/room_rank/index.html)

## 実装判断

- 商品調査エンジン: **実装可能**。楽天市場商品検索APIを使用する。
- 自動更新: **実装可能**。低頻度、キャッシュ、差分更新、取得日時表示を入れる。
- 紹介文生成: **実装可能**。公式取得データのみを事実として使い、未購入表現ルールと禁止表現チェックを入れる。
- 投稿準備キュー: **実装可能**。ROOM公式画面へ貼り付けやすい形で出力する。
- ROOM自動投稿: **実装しない**。規約が機械的投稿を明示的に禁止している。
- 売上自動取得: **公式に許可された取得方法が確認できるまで実装しない**。公式レポートの手動エクスポート等を入力にする。
