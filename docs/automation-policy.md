# 楽天ROOM・OKINAWA SELECT 自動化方針

## 最優先目標

投稿数ではなく、沖縄旅行に関心のある20〜40代が購入しやすい商品を継続的に紹介し、成果報酬を伸ばす。

## 商品選定

対象は次の4ジャンルを優先する。

1. 沖縄旅行の便利グッズ
2. 沖縄のお取り寄せグルメ
3. 沖縄雑貨・ファッション
4. 旅行・撮影用品

楽天市場商品検索APIから取得した候補を、レビュー平均、レビュー件数、送料、想定価格帯、ポイント倍率、Instagramとの相性で比較する。未購入商品を使用済みと表現しない。価格、割引、送料、レビューは更新時点で取得できた値だけを扱い、公開画面では楽天市場の商品ページを最終情報とする。

AmazonはアソシエイトのトラッキングIDを含む検索リンクを併記し、Amazonの価格・在庫はサイト内へ固定表示しない。Creators APIの利用条件を満たした後に、公式APIによる商品情報の自動更新へ移行する。Amazonや楽天の商品ページをスクレイピングしない。

## 販売先リンクの表示ルール

- 楽天市場とAmazonの両方で同一商品を確認できた場合は、両方のリンクを表示する。
- 片方でしか商品を確認できない場合は、確認できた販売先のリンクだけを表示する。
- 取扱状況を確認できない販売先のリンクは表示しない。
- 類似商品や検索結果が存在するだけでは、同一商品の取扱確認として扱わない。
- 日次更新で取扱終了を検知した場合は該当リンクを非表示にし、もう一方が有効なら商品カードは残す。両方とも無効なら商品カードを公開対象から外す。

## 自動化する範囲

- 商品候補の検索と重複排除
- レビュー・送料・価格帯を使った順位付け
- 独自紹介文の下書き
- サイトの商品データ更新
- 投稿候補一覧と差し替え候補の生成
- 投稿後のURL・掲載状態・重複の確認（許可された方法がある範囲）

## ROOM投稿

ROOM内の他ユーザー投稿を起点にした再コレは標準フローにしない。ROOM利用規約はプログラムによる機械的な投稿・コメントを禁止しているため、Codexは投稿ボタンを押さない。商品候補、独自紹介文、ハッシュタグ、楽天市場の通常商品URLを投稿キューとして用意し、ユーザーがROOM公式画面で最終投稿する。OKINAWA SELECT用のアフィリエイトURLはROOM投稿キューへ流用しない。ROOM側が投稿時に専用のアフィリエイトリンクを作成する。

## ユーザーが行う作業

- 実際に所有・購入した商品のオリジナル写真撮影
- 投稿前に必要となる本人認証
- 楽天が人による操作を要求する最終投稿操作
- 実体験として表現する文章の確認

既存の16投稿は削除しない。差し替え提案は、比較根拠と新しい候補を示してから行う。
